WHAT COUNTS AS A READ (all four must be true, checked once per second) ---------------------------------------------------------------------- 1. The visitor has scrolled at least 60% of the way down the article. 2. The tab has been VISIBLE for long enough (about 35% of a typical 238 words-per-minute reading time, clamped to 20-90 seconds). A background tab or a 5-second bounce never gets there. 3. At least one REAL user action happened (wheel, mouse move, tap, key press). Browsers mark genuine actions with event.isTrusted = true; scripts that fake events get isTrusted = false, so simple bots are ignored. Bots that drive a real browser with real input are not stopped; this screens out casual automation, not determined automation. 4. It has not already fired on this page view (it fires at most once). NOTES ----- - Needs no Google Analytics setup: the event can be read in the Data API by page path + event name. Do NOT mark it as a "key event": that would add reads to the conversion count and distort the conversion reporting. - Works only where the main GA4 snippet (gtag) is loaded; otherwise it exits. - Included from layouts/insights/single.html. Data attributes on the
tag carry the values Hugo knows at build time (word count). */}}
